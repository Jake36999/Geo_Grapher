## Implemented

The new `grounded-actor-prompt-v3` public contract:

- Distinguishes `citations[].path` (a delivered file path) from `paths[][]` (a delivered code-subject qualified name). A wrong qualified-name citation now gets a repairable `CITATION_FILE_PATH` diagnostic rather than a false missing-retrieval diagnosis.
- States required answer provenance explicitly by public task category. Documentary/source contradictions require `basis:source`; helper control-flow and static-path tasks have their own declared basis. Fact minimality cannot silently omit those labels. Inappropriate basis alternatives are filtered from the supplied vocabulary.
- Provides Markdown heading/paragraph citation anchors derived from the source parser, not the answer oracle. `guide.md`'s historical section yields 6–9. The validator asks for complete cited section context when a partial section citation is used; it still cannot prove semantic staleness or relevance solely from a section boundary.
- Exposes the public focus/pin path requests. Extra or unrelated paths are rejected rather than rewarded for sounding helpful.

`evaluation.transport_schema.compile_transport_schema` specializes the transport schema with enums for complete fact labels, delivered citation filenames and known subject names. It also bounds path count by the public requested anchors. It defaults to omitting **only `uniqueItems`**, with a removal audit and schema hashes. Other known unsupported validation keywords can be explicitly configured; there is no blind global removal of bounds. Only schema keyword positions are transformed: a property named `uniqueItems` and data inside enum values remain intact. Original schema constraints plus oracle-free grounding remain authoritative locally.

New handoff requests include a ready `response_format` and `schema_transport` audit. The process adapter includes the same response format in both initial and repair requests, counted within the original cumulative budget. Use those fields in the external bridge instead of reconstructing an unconstrained array-of-strings schema. If the endpoint rejects structured-output mode entirely, record that failure and any explicitly chosen `json_object` fallback; do not silently label the fallback strict or skip local validation. This compiler is an explicit compatibility profile, not a claim that a particular endpoint has been remotely verified.

All validation remains oracle-free at model/repair time. The full independent rubric remains separate. The optional one-repair loop still shares the original cumulative input/output/provider budget and retains every attempted answer. These tests do not establish improved paid-model success.
